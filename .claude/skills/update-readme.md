지금까지 작업한 내용을 바탕으로 README.md를 최신 상태로 업데이트한다.

## 진행 순서

1. `git log --oneline -20`으로 최근 커밋 이력을 확인한다.
2. `templates/` 디렉토리 구조를 재귀적으로 확인한다 (`find templates/ -type f`).
3. 주요 `.tf`, `.tfvars` 파일들을 읽어 현재 구현 상태를 파악한다.
4. 현재 README.md를 읽는다.
5. 변경이 필요한 부분(디렉토리 구조, 파일 설명, 변수 목록, 네트워크 구조, 실행 흐름 등)을 파악한다.
6. README.md를 실제 코드 상태와 일치하도록 수정한다.

## 주의사항

- 있는 내용을 삭제하지 말고 **추가하거나 수정**하는 방향으로 작업한다.
- 코드에 없는 내용을 추측해서 쓰지 않는다.
- 변수 테이블, 디렉토리 구조 tree, 실행 흐름은 실제 파일 기준으로 정확하게 반영한다.
